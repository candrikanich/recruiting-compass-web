# Admin Ops Health (#2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the admin operational visibility + one safe control — per-job cron sparklines & failure alerts, a guarded "Run now" for non-destructive jobs, and a DB health panel (row counts, storage, orphaned preview).

**Architecture:** A `requireAdmin` `POST /api/admin/cron/trigger` endpoint with a hard server-side allowlist invokes a cron via a Nitro internal `$fetch` carrying `CRON_SECRET` (so the run records itself in `cron_runs`), audited via a new `cron.trigger` action. The Jobs tab gains client-derived sparklines/alerts + Run-now buttons. A `requireAdmin` DB-health endpoint aggregates counts/storage/orphaned-preview for the Health tab.

**Tech Stack:** Nuxt 3 (Vue 3 `<script setup>`, TS strict), Nitro API routes, Supabase (`useSupabaseAdmin()` service role), Zod, Chart.js (via `AdminChart`), Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-08-17-admin-ops-design.md`

## Global Constraints

- `requireAdmin(event)` before any work in both new endpoints.
- **Cron trigger allowlist is the security gate (server-side, not UI):**
  - Triggerable: `daily-suggestions, generate-notifications, weekly-digest, health-ping, video-health-check`.
  - dryRun-only (force `dryRun=true` server-side): `orphaned-storage-sweep`.
  - Hard-blocked → 403 always: `process-account-deletions, notification-prune, cleanup-expired-invites`.
  - Unknown jobName → 403.
- `CRON_SECRET` stays server-only (never sent to client). Cron invocation = Nitro internal `$fetch('/api/cron/<job>', { headers: { 'x-cron-secret': process.env.CRON_SECRET } })` — `requireCronAuth` accepts the `x-cron-secret` header; the call records a `cron_runs` row via `withCronRun`.
- Every trigger audited: add `"cron.trigger"` to `AdminAuditAction`; `logAdminAction(event,{action:"cron.trigger",meta:{jobName,dryRun}})` (fire-and-forget, never throws).
- DB-health endpoint = count/SELECT + storage-list only; no mutation. Per-check failures degrade gracefully (show "—", never 500 the whole panel).
- Reuse `components/Admin/AdminChart.vue` (sparkline), `AdminStatTile.vue`, `AdminDataTable.vue`. No raw hex/rgba (`audit:tokens`); chart hex needs `// audit-ignore`.
- Client composables `{ data, loading, error, ... }`; admin fetches attach `useAdminAuthHeaders`.
- TS strict, no `any` except tests. Immutability via spread. Unit tests under `tests/unit/**` `.spec.ts`. Components in `components/Admin/` (capital A).
- E2E admin pages need `NUXT_PUBLIC_ADMIN_HOST=localhost:3003`.

// server/api/admin/cron/trigger.post.ts
import { z } from "zod";
import { requireAdmin } from "../../../utils/auth";
import { logAdminAction } from "../../../utils/adminAudit";

export const TRIGGERABLE_JOBS = [
  "daily-suggestions", "generate-notifications", "weekly-digest",
  "health-ping", "video-health-check",
] as const;
export const DRYRUN_ONLY_JOBS = ["orphaned-storage-sweep"] as const;
export const BLOCKED_JOBS = [
  "process-account-deletions", "notification-prune", "cleanup-expired-invites",
] as const;

const bodySchema = z.object({ jobName: z.string(), dryRun: z.boolean().optional() });

export default defineEventHandler(async (event) => {
  await requireAdmin(event);
  const { jobName, dryRun: reqDryRun } = bodySchema.parse(await readBody(event));

  const isTriggerable = (TRIGGERABLE_JOBS as readonly string[]).includes(jobName);
  const isDryRunOnly = (DRYRUN_ONLY_JOBS as readonly string[]).includes(jobName);
  if (!isTriggerable && !isDryRunOnly) {
    throw createError({ statusCode: 403, statusMessage: "This job cannot be triggered from the admin UI" });
  }
  const dryRun = isDryRunOnly ? true : Boolean(reqDryRun);

  const secret = process.env.CRON_SECRET;
  if (!secret) throw createError({ statusCode: 500, statusMessage: "Cron secret not configured" });

  let result: unknown;
  try {
    result = await $fetch(`/api/cron/${jobName}`, {
      headers: { "x-cron-secret": secret },
      ...(dryRun ? { query: { dryRun: 1 } } : {}),
    });
  } catch {
    // The cron records its own error row; surface a generic failure.
    throw createError({ statusCode: 502, statusMessage: "Job run failed — see the job's recent runs" });
  }

  logAdminAction(event, { action: "cron.trigger", meta: { jobName, dryRun } });
  return { ok: true, jobName, dryRun, result };
});
```

Note: if the Nitro `$fetch`/`readBody`/`createError` auto-imports aren't visible to the vitest unit context, add explicit imports from `h3`/`ofetch` to match how other `server/api/**` files import them (check a sibling). Adapt the TEST stubs, never weaken the allowlist.

// utils/cronDashboard.ts
interface RunRow { job_name: string; status: string; duration_ms: number | null; started_at: string }

export function recentForJob<T extends RunRow>(recent: T[], jobName: string, n: number): T[] {
  return recent.filter((r) => r.job_name === jobName).slice(0, n);
}

// `recent` is ordered most-recent-first (cron-runs.get.ts orders started_at desc).
export function consecutiveFailures(recent: RunRow[], jobName: string): number {
  let n = 0;
  for (const r of recentForJob(recent, jobName, Number.MAX_SAFE_INTEGER)) {
    if (r.status === "success") break;
    n += 1;
  }
  return n;
}

export function sparklineData(recent: RunRow[], jobName: string, n = 14) {
  // Oldest→newest for a left-to-right trend; height = duration, colored later by status.
  const rows = recentForJob(recent, jobName, n).slice().reverse();
  return {
    labels: rows.map((r) => r.started_at),
    datasets: [{ data: rows.map((r) => r.duration_ms ?? 0) }],
  };
}
```

```ts
// server/api/admin/ops/db-health.get.ts
import { requireAdmin } from "../../../utils/auth";
import { useSupabaseAdmin } from "../../../utils/supabase";

const KEY_TABLES = [
  "users", "family_units", "schools", "coaches", "interactions",
  "offers", "events", "athlete_messages", "cron_runs", "admin_audit_log",
];

export default defineEventHandler(async (event) => {
  await requireAdmin(event);
  const db = useSupabaseAdmin();

  const rowCounts = await Promise.all(KEY_TABLES.map(async (table) => {
    try {
      const { count, error } = await db.from(table).select("id", { count: "exact", head: true });
      return { table, count: error ? null : (count ?? 0) };
    } catch { return { table, count: null }; }
  }));

  let storage: { bucket: string; objects: number | null }[] = [];
  try {
    const { data: buckets } = await db.storage.listBuckets();
    storage = await Promise.all((buckets ?? []).map(async (b: { name: string }) => {
      try {
        const { data } = await db.storage.from(b.name).list("", { limit: 1000 });
        return { bucket: b.name, objects: data?.length ?? 0 };
      } catch { return { bucket: b.name, objects: null }; }
    }));
  } catch { storage = []; }

  let orphanedPreview: { deadUsers: number; objects: number; expiredExports: number } | null = null;
  try {
    const secret = process.env.CRON_SECRET;
    if (secret) {
      const sweep = await $fetch<{ perBucket?: Record<string, { deadUsers?: number; objects?: number }>; expiredExports?: number }>(
        "/api/cron/orphaned-storage-sweep", { headers: { "x-cron-secret": secret }, query: { dryRun: 1 } },
      );
      const per = Object.values(sweep.perBucket ?? {});
      orphanedPreview = {
        deadUsers: per.reduce((s, p) => s + (p.deadUsers ?? 0), 0),
        objects: per.reduce((s, p) => s + (p.objects ?? 0), 0),
        expiredExports: sweep.expiredExports ?? 0,
      };
    }
  } catch { orphanedPreview = null; }

  return { rowCounts, storage, orphanedPreview };
});
```
